# 安康药管家安全加固说明

## 本次已完成

- 连续密码错误计数保存在数据库；第 5 次失败后锁定 15 分钟。
- 登录页显示锁定倒计时，家庭管理员可以解锁，重置密码会同步解锁。
- 登录必须携带两分钟有效、只能使用一次的点击式人机验证令牌，并限制验证接口频率。
- 用户名不存在时返回统一的“账号或密码错误”，避免公开判断账号是否存在。
- 跨域来源由 `ALLOWED_ORIGINS` 白名单控制，不再允许任意来源携带凭证访问。
- 上传文件同时校验扩展名、大小和真实文件头；药品图、订单截图和收货照片需要登录后才能读取。
- 家庭代购记录不能绕过订单流程直接修改、删除或确认收货。
- 收货必须核对照片、实收盒数、国药准字号和包装状态；不一致时禁止入库并通知家庭守护端。
- 登录锁定和一次性人机令牌已有自动化测试。

## 公网部署必须做到

1. 只通过 HTTPS 对外开放网站。浏览器开发者工具会显示本机即将发送的请求内容，这是正常现象；HTTPS 保护的是内容离开设备后的网络传输，前端自行加密密码不能代替 HTTPS。
2. 服务器安全组只开放 80、443，8088 和 3306 不直接暴露公网。
3. `JWT_SECRET`、数据库密码、Gmail 应用专用密码只放服务器环境变量，不写入代码、部署包或 Git。
4. Nginx 需要转发真实来源地址：`X-Forwarded-For` 和 `X-Real-IP`，应用已开启转发头处理。
5. `ALLOWED_ORIGINS` 只填写实际使用的 HTTPS 域名；同域部署时浏览器不需要跨域。

## 后续可选增强

- 当前点击式验证适合家庭系统的基础防自动请求。若公网遭遇批量机器人攻击，接入 Cloudflare Turnstile 或同类托管验证码。
- 当前登录令牌保存在浏览器本地存储。页面没有使用 `v-html` 等高风险动态 HTML；如需要进一步降低令牌被脚本读取的风险，可在后续版本改为 HttpOnly、Secure、SameSite Cookie。
- 对上传的健康相关照片增加自动清理期限、备份加密和管理员审计策略。
