# 小刘云统一平台：架构与面试讲解

## 一句话介绍

我从零到一开发并部署了一个以 Spring Boot 2.7、Vue 3、MySQL、Nginx 和华为云 OBS 为核心的多业务平台：个人博客负责公开内容，一级门户负责产品入口，DSMS 负责家庭慢病用药协同，个人记账负责私有消费数据，软件服务模块负责公开获客和交付过程管理。

## 为什么不是四套互不相关的网站

它们共享一个域名和后端基础设施，但通过路径、数据表、权限和前端构建入口隔离：

```text
xiaoliudev.com/
├── /                         个人博客（静态公开）
├── /cloud-hub/               一级门户与个人记账、软件服务
├── /kanglian-cloud/          DSMS
└── /api/                     Spring Boot API
```

这样可以复用 HTTPS、Nginx、JWT 登录、审计日志和通知能力，又不会把个人记账流水和家庭购药资金混在一起。

## 为什么同一套 Vue 页面能适配电脑和手机

不是做两套页面，而是使用同一份语义结构，通过 CSS Grid/Flex、`clamp()`、媒体查询和移动端列表替换宽表格：

- 宽屏是侧栏、指标卡和多列 Bento 布局；
- 窄屏侧栏变抽屉，多列变单列；
- 宽表格在手机上变为卡片列表；
- 弹窗宽度使用 `min(600px, 94vw)`，不会超过屏幕；
- `prefers-reduced-motion` 会关闭强动画，兼顾可访问性。

面试可背：**响应式不是缩小桌面页面，而是同一业务语义在不同断点选择合适的信息密度和交互组件。**

## 个人记账如何做到“自学习选项”

它不是昂贵的 AI 模型。用户第一次输入“榴莲摊”并保存流水后，数据库已经有这条交易对象。建议接口按当前用户和当前账本执行分组统计：

```sql
GROUP BY counterparty
ORDER BY COUNT(*) DESC, MAX(transaction_time) DESC
```

因此常用和最近使用的地点会自动排到前面。查询条件始终包含 `owner_user_id` 和 `ledger_id`，朋友之间不会互相看到建议。

面试可背：**先用可解释的频率加新近度排序解决真实问题，数据规模和价值不足时不盲目引入推荐模型。**

## 游客不登录，如何安全查看自己的咨询进度

提交成功后后端生成：

- 不可预测的咨询编号；
- 144 位随机访问码。

访问码原文只返回一次，数据库只保存 SHA-256 摘要。查询时对输入再次计算摘要，并用常量时间比较。公共详情使用字段白名单，不返回联系方式、摘要、客户端指纹或管理员用户 ID。接口还有真人验证和 IP 限流。

这避免了短信验证码费用，也比“随便输入账号密码自动注册”规范。

## OBS 文件为什么需要 `file_asset` 表

OBS 只负责保存二进制对象，不知道这个文件属于谁、哪一个家庭、哪一笔订单，也不知道业务上能否删除。因此数据库需要保存：

- `object_key`：OBS 对象位置；
- `owner_user_id`、`family_id`：所有者和家庭边界；
- `business_type`、`business_id`：对应订单或凭证；
- `content_type`、`file_size`、`sha256`：类型、大小和完整性；
- `status`、`deleted`：生命周期。

下载时前端不直接拼公开 URL，而是先请求后端；后端校验 JWT、角色和家庭关系后，再生成短期访问地址。

面试可背：**对象存储保存文件，数据库保存业务元数据和授权边界，两者职责不同。**

## AK/SK 为什么不能写进代码

AK 是身份标识，SK 相当于云 API 密码。写进代码或 GitHub 后，即使删除提交，Git 历史仍可能保留。因此生产环境放在权限为 `600 root root` 的 `/etc/dsms-backend.env`，systemd 启动服务时注入，Spring Boot 通过环境变量读取。

## Maven、systemd 和 Nginx 各负责什么

- Maven `clean package`：删除旧构建并编译、测试、打 JAR；
- systemd：守护 Java 进程，实现开机自启、异常重启和统一日志；
- Nginx：终止 HTTPS、提供静态文件、按路径反向代理 `/api/`；
- MySQL：保存结构化业务数据；
- OBS：保存截图、发票等大文件。

## 一段可直接用于面试的项目讲解

“这个项目最初是家庭慢病用药系统，后来我把它演进成一个统一数字平台。后端使用 Spring Boot、Spring Security、JWT 和 MyBatis-Plus，MySQL 按业务域分表；前端使用 Vue 3 和 Vite，通过两个构建入口分别输出 `/cloud-hub/` 和 `/kanglian-cloud/`。文件上传接入华为云 OBS，但所有下载必须经过后端的用户和家庭关系校验。个人记账支持用户级数据隔离、快速录入、自定义地点自动沉淀、月度分类和地点洞察。公开软件服务不强迫用户注册，而是通过随机访问码查询进度，数据库只存访问码摘要。上线使用 Nginx、systemd 和带自动回滚的脚本，每次发布都会做数据库备份、哈希校验、本机接口检查和公网路径验收。”
