## 本轮审查中发现并修复的问题

1. 个人记账原页面仍偏传统后台，快速录入摩擦较大：改为十秒快速记账工作台。
2. 自定义分类和消费地点没有自动复用：新增按用户、账本、频率和最近时间排序的建议接口。
3. 月度统计只有分类，没有回答“花在哪里”：新增地点汇总、每日脉冲、日均和单笔最高。
4. 数据库金额只校验最小值，超大金额可能到数据库才报错：增加与 `DECIMAL(14,2)` 一致的最大值校验。
5. 游客查询接口缺少频率控制：增加每 IP 每小时 60 次限制。
6. 咨询编号依赖进程计时：改为日期加 72 位安全随机数，降低重启碰撞和可预测性。
7. 公共消息可能携带管理员内部用户 ID：公共视图改为显式白名单字段。
8. 博客升级可能再次误伤子系统：增加只替换三个文件、失败自动恢复的独立脚本。
