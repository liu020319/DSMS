# DSMS OBS 文件中心与购药凭证测试报告

测试日期：2026-08-22
测试范围：本地代码、后端自动化测试、前端生产构建。未使用生产 AK/SK，未执行服务器 SQL，未验证公网 OBS 端到端链路。

## 自动化结果

执行：

```powershell
mvn '-Dmaven.repo.local=D:\CodexWorkFiles\.m2-repository' clean package
```

结果：`BUILD SUCCESS`；19 个后端自动化测试全部通过，0 失败、0 错误、0 跳过；生成 `backend/target/medicine-system-1.0.0.jar`。

新增覆盖：

- JPG/PNG/GIF/WEBP 内容签名识别；
- 非图片内容拒绝；
- 本地文件写入读取；
- 本地路径穿越拒绝；
- 本家庭守护人可绑定付款凭证；
- 其他家庭守护人拒绝；
- 未支持的凭证类型在绑定文件前拒绝；
- 原有登录锁定、密码、账号与家庭范围测试继续通过；
- 文件上传成功会写入文件台账；数据库写入失败会补偿删除刚上传的对象。
- 其他家庭账号不能读取不属于本家庭的文件。
- 老人解绑后，原守护人不能继续读取该老人的跨订单凭证时间线。

## 前端构建

执行：

```powershell
npm run build
```

结果：Vite `4.5.14`，2275 个模块转换成功，生成 `frontend/dist/index.html` 与哈希静态资源。

已知非阻断警告：Element Plus 和 ECharts 产物较大；应在后续首屏性能专项中进一步按路由/组件拆包，不应只调大警告阈值掩盖问题。
