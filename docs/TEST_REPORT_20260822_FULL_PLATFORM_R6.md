## 修复回归

### 人机验证

首次点击早于最短等待时间时返回 429，但挑战不会被删除；等待后使用同一挑战可成功，避免“操作过快后永远验证失败”。

### 邮件提醒

- DSMS 邮件收件人兼容 `MAIL_RECIPIENT` 与旧 `MAIL_TO`。
- 邮件异步任务被拒绝时会记录失败状态。
- 临时 SMTP 失败最多重试 3 次。
- 管理员可查看不含密码的邮件状态并发送同步测试邮件。
- 博客评论/留言邮件改用有界线程池，不再因短时并发直接静默丢弃。

### 版本完整性

发布物明确分成博客服务、DSMS、统一门户和后端 JAR。部署脚本同时替换 `/kanglian-cloud/` 与 `/cloud-hub/`，避免“门户是新版本、DSMS 仍是旧版本”。

## 部署后必须再验证

以下依赖真实服务器和外部服务，本地不能冒充通过：

1. Gmail 实际收到博客测试邮件和 DSMS 测试邮件。
